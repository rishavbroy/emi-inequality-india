# Diagnostic outputs

This directory contains generated review and validation outputs that are not themselves maintained as paper source files.

## Retention rule

Keep an output only when it is required by the paper/application samples, by a declared replication or validation check, or because it provides bounded reviewer evidence that would be expensive or ambiguous to reconstruct manually. Disposable debugging output should not be committed.

Core paper-facing tables and figures belong under their dedicated output directories. Extended diagnostics remain clearly separated from paper-facing results so their presence does not imply that every diagnostic is a publication claim.
